# ShopEasy (React)

A small shop built with React + Vite. Part of the Coding Club workshop.

## Run it

```bash
npm install
npm run dev
```

Then open the link shown in the terminal (usually http://localhost:5173).

## Project structure

```
src/
├── main.jsx         starts React
├── App.jsx          main page: cart state, layout
├── ProductCard.jsx  one reusable product card
├── products.js      all product data
└── App.css          styles
```

## Try it yourself (after forking)

1. Add a new product in `src/products.js` (one line).
2. Change the banner text in `App.jsx`.
3. Change a colour in `App.css`.
4. Commit, push and open a pull request!
